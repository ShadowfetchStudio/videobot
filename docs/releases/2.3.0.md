# VideoBot 2.3.0 — Apple silicon research workspace

## Supported platform

Only macOS on Apple silicon is maintained from this release onward. Earlier Windows/Linux downloads remain historical. The DMG is ad-hoc signed, not Developer ID signed or Apple notarized. FFmpeg/ffprobe and a supported JavaScript runtime remain external dependencies, with readiness information and setup diagnostics in the app.

## Fixes

- Stable row identities prevent filter changes from selecting an unrelated queue job. Queue and Library preserve their own selection.
- Generic HLS sources with matching manifest filenames no longer collide; existing Generic records receive corrected identities without deleting history.
- Audio-only extraction ignores video-height ceilings; FLAC/AAC/Opus/AIFF URLs route to media discovery.
- Typed tools paths are applied and validated; priority edits preserve untouched schedules.
- Status, progress and the activity-log toggle use a fixed footer. Settings panes scroll independently.
- Relink checks active transcript revisions and refuses incomplete older bundle copies.
- A failed clip registration reports the retained output path and its recovery route.
- Unknown worker actions fail explicitly instead of falling through to queue execution.

## New capabilities

- Recovery center with verified bundle import and backup restoration into a separate database/window.
- Portable media collections with completion markers, source manifests and active transcript imports.
- Transcript correction with retained revisions and reviewed-text provenance.
- Named excerpts and sequential multi-clip export.
- Indexed whole-word/phrase transcript search alongside existing substring matching.
- Opt-in macOS launch-agent queue runs and bounded watched sources. Authentication cookies are not persisted.
- Native application icon, remembered window size and setup readiness information.
- Mac-only, dependency-locked source/package CI and embedded source/runtime build metadata.

## Validation and limits

The development regression suite passed 75 tests, including a real spoken fixture through the optional Metal backend. CI without that optional model runs 74 tests and skips the one model-dependent test. Packaged smoke checks exercised local downloads, browser inspection, playback, clip creation and transcription of actual spoken words. Dependency auditing found no known vulnerabilities in audited dependencies; the private application package itself is not a PyPI advisory entry.

The previously crashing filter/select/clear sequence completed with the stable-row view and preserved only the intended selection. The macOS accessibility inspector can still omit the table hierarchy after a filter refresh. Full screen-reader qualification remains open; accessibility has not been disabled. Stable rows keep first-seen display order until reopening the view; queue execution still respects priority and schedule.

Background launch-agent installation is opt-in and not performed by downloading or opening the application. The background configuration and queue engine were tested separately; a production service was not enabled on the developer's machine. Authenticated websites and every possible source format are not certified by local smoke tests.

Optional Apple Metal transcription is available through whisper.cpp and a user-selected local GGML model. Speaker labeling is deferred to a later update. Semantic search and a full video editor are not included. The bundled CPU engine supports tiny/base/small Whisper models.

See [the current guide](../MAC-2.3.md) for workflows and recovery behavior. Older audit documents describe older versions.
